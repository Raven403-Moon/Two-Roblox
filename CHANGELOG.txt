[Two-Roblox 업데이트 및 개선 작업 내역]

1. 윈도우 타이틀 및 사이드바 텍스트 간소화
- main.py:
  * 윈도우 타이틀에서 불필요한 서브 문구를 제거하고 심플하게 "Two-Roblox"로 변경
  * 사이드바 상단 브랜드 아래의 "Multi-Client Manager" 텍스트 레이블을 제거하여 깔끔한 미니멀 디자인 완성

2. README.md 상세 구현 코드 예시(Snippet) 대폭 확충
- README.md:
  * Win32 커널 싱글톤(ROBLOX_singletonEvent / Mutex) 선점 및 handle64 핸들 격리 코드
  * 단회성 인증 티켓(Auth Ticket) 발급 및 부트스트래퍼 우회 CLI 직접 실행 파라미터 빌드 코드
  * Place ID / Job ID 화이트리스트 정규식 인젝션 방어 코드
  * 독립 프로필 PySide6 WebEngine 공식 로그인 창 임베딩 및 .ROBLOSECURITY 쿠키 자동 캡처 코드
  * Windows DPAPI(CryptProtectData) 연동 및 PBKDF2 48만회 AES-Fernet 계정 암호화 코드
  * 버튼 포커스 점선 윤곽선(PE_FrameFocusRect) 제거 NoFocusStyle(QProxyStyle) 코드
  * 콘솔 창(cmd) 없는 pythonw.exe 기반 관리자 권한 승격 재실행 코드

3. 그룹 선택 콤보박스 가독성 및 UI/UX 전면 개선
- ui/styles.py 및 main.py:
  * QComboBox 전용 스타일을 새롭게 작성하여 드롭다운 리스트(QAbstractItemView)에 딥 다크 배경(#0F1118)과 순백색 굵은 텍스트(#FFFFFF), 로얄 블루(#2563EB) 선택 하이라이트를 적용하여 글씨가 묻히는 문제 완전 해결
  * 콤보박스 우측에 정돈된 화살표(down-arrow) 및 분리선 추가
  * QListView 뷰 델리게이트를 명시적으로 장착하여 커스텀 다크 테마가 100% 깔끔하게 렌더링되도록 보장
  * 계정 테이블의 "그룹" 태그 텍스트에 선명한 라이트 블루(#93C5FD) 포그라운드를 적용하여 가독성 강화

4. 보안 취약점 진단 및 방어 보완 (Security Hardening)
- core/roblox_api.py: Place ID / Job ID 정규식 화이트리스트 검증 및 티켓 정제
- core/updater.py: tempfile.TemporaryDirectory 안전 격리 임시 폴더에서 인스톨러 다운로드/실행
- core/crypto_store.py: DPAPI .vault_key 파일에 Windows 숨김 속성(FILE_ATTRIBUTE_HIDDEN) 자동 부여

5. 관리자 권한 재실행 시 cmd 콘솔 창 완전 제거 (순수 GUI 실행)
- core/multi_instance.py의 restart_as_admin 개선: pythonw.exe 자동 탐지, FreeConsole 분리, os._exit(0) 즉시 종료
- main.py 시작 시 콘솔 창이 붙어있는 경우 GetConsoleWindow 및 ShowWindow(SW_HIDE)로 즉각 숨김 처리

6. 버튼 클릭 시 글자 주위 점선 윤곽선(Focus Rectangle) 완전 제거
- NoFocusStyle(QProxyStyle) 구현 및 setFocusPolicy(Qt.NoFocus) 전면 적용

7. Black, White, Blue 3색 계열의 미니멀 모던 UI 개편
- 블랙(#090A0D, #0F1015, #14161E), 화이트(#FFFFFF, #94A3B8), 블루(#2563EB, #1D4ED8, #3B82F6) 미니멀 다크 룩

8. 계정 추가 시 공식 로그인 웹 화면 직접 표출 (UX 극대화)
- ui/add_account_dialog.py: 공식 로그인 화면 직접 표시 및 0.5초 내 쿠키 자동 추출/등록

9. 64비트 Roblox User ID 오버플로우 오류 수정
- ui/avatar_cache.py 및 main.py: Signal(object, ...) 및 문자열 안전 매칭

10. 로블록스 자동 업데이트 및 무결점 로그인 연계
- core/updater.py: 버전 실시간 감지 및 인스톨러 격리 무중단 자동 업데이트, 최신 Auth Ticket 주입으로 로그인 유지

11. 고성능 메모리 안전 순수 Rust 코어 전면 재코딩
- Rust 1.75+ 기반 src/ 디렉터리 전체 재구현
- windows-sys 0.59 Win32 커널 싱글톤 선점, DPAPI FFI, AES-256-GCM, u64 ID 모델
- target/release/two_roblox_rs.exe 3.6MB 단일 네이티브 바이너리 빌드 완료

12. build.ps1 원클릭 고속 자동 빌드 및 배포 패키징 시스템 구축
- build.ps1: 대화형 및 CLI 스위치(-All, -Upx, -Setup, -SourceZip, -GpgSign) 지원
- UPX LZMA 패커 연동으로 1.3MB 초경량 Two-Roblox-Portable.exe 포터블 바이너리 생성
- Inno Setup 6 (ISCC) 연동 다국어 인스톨러(Two-Roblox-Setup-v*.exe) 자동 생성
- 소스코드 클린 아카이브(Two-Roblox-v*-source.zip) 자동 생성
- GPG 디지털 분리 서명(.asc) 및 SHA-256 체크섬(SHA256SUMS.txt) 자동 생성
- winres 기반 Windows 실행 파일 아이콘(assets/icon.ico) 및 바이너리 메타데이터 내장
